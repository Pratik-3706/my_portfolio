# my_portfolio

My personal site. Three files, no framework, no build step — open `index.html`
and it runs.

```
index.html   markup and copy
style.css    tokens, layout, the alternate palettes
main.js      the shell and the easter eggs
```

Light and dark follow the OS; the `theme` link in the nav overrides it.

There is a shell behind the backtick key. Start with `help`, then `ls`.
